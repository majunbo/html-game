### 🎮 AI 辅助 HTML5 游戏开发实践：超级马里奥复刻

本项目旨在探索大语言模型在网页游戏开发中的实际应用能力与边界。通过对比不同模型的生成质量，记录了从提示词到可玩原型的完整迭代过程。

#### ✨ 项目特色

-   **零依赖纯原生实现**：游戏完全基于原生 HTML5 Canvas + Vanilla JS 构建，无任何第三方引擎或框架依赖。单文件即可运行，极致轻量，便于源码阅读与二次修改。
-   **AI 生成代码对照实验**：两个版本使用完全相同的初始 Prompt，直观呈现 Grok Fast 与 Hy4 Preview 在逻辑完整性、Bug 密度及修复成本上的差异，为 AI 编程选型提供真实参考。
-   **国际化多语言支持**：支持 7 种主流语言（简体中文、繁體中文、English、日本語、Português、Español、Français），具备浏览器语言自动识别与 localStorage 状态记忆。
-   **渐进式人机协作范式**：并非一次性生成成品，而是记录了“AI 生成 → 人工测试 → 精准反馈 → AI 修复”的完整闭环，展示了当前阶段人类开发者作为“AI 代码审查员”的最佳实践路径。

#### 🕹️ 核心游戏机制与功能

1. **六大独立主题与梯度关卡系统**
   - **关卡梯度进阶**：草原平原 → 沙漠/黄昏 → 星夜洞窟 → 熔岩火山 → 冰雪世界 → 幽暗城堡，每关具备完全独立的障碍地貌与地形布局，敌人巡逻移速与跳坑机关难度逐关递增。
   - **主题专属配色与氛围特效**：每关天空渐变、远山草丛、地面地砖、石块与砖块配色完全独立；暗色主题（星夜/熔岩/鬼域）配有动态闪烁星空，冰雪关卡具备全局实时飘雪粒子。
2. **手感调校与平台动作引擎**
   - **跳坑手感宽容度**：内置土狼时间（Coyote Time，离地短时间内仍可起跳）、跳跃预输入（Jump Buffer，落地前提前按键落地瞬间起跳）、坑沿吸附（Ledge Snap）。
   - **动态移动平台与错层踏板**：程序化正弦平滑移动平台，支持单向碰撞与角色站立随动。
3. **敌人 AI 行为系统**
   - **悬崖守卫机制**：每个跳坑落点均有板栗仔严密把守，考验起跳与空中微操。
   - **智能巡逻感知**：敌人在悬崖边与深坑边缘会自动感知并主动掉头巡逻，告别无脑坠坑。
4. **道具收集与 100% 可达问号设计**
   - **散落金币与金币弧线**：悬崖坑上方金币弧线与地面金币长廊，收集 +50 积分并伴随旋转动画与音效。
   - **全关卡问号 100% 可顶取**：问号方块下方均保留充足的起跳空间与错层台阶，即使双层砖阵也能从容顶取；15% 概率触发高爆幸运方块（+500 积分与专属粒子）。
   - **通关庆祝盛典**：终点夺旗触发漫天烟花盛典，过关结算界面触发全屏彩色纸屑彩带与 100~600 惊喜幸运随机奖励。
5. **UI、跨浏览器适配与交互系统**
   - **关卡开场提示系统**：每关开局展示 4 秒精致高对比度半透明卡片提示，主标题（30px）与副标题（16px）采用与 HUD（关卡/积分/生命）高度一致的纯白立体黑描边质感。
   - **Canvas 字体引擎规范化**：修复 Canvas 2D 上下文解析 CSS 变量失效的问题，确保在各种分辨率下矢量字体清晰渲染。
   - **跨端矢量 SVG 国旗多语言选择器**：采用高质量内联 SVG 国旗，彻底解决 Chrome/Edge/Firefox 等各浏览器在 Windows/Linux/Mac 下 Emoji 国旗显示为国家缩写（如 CN/HK/US）的兼容性痛点。
   - **精准浏览器语言自动识别**：页面首次加载时自动依序检测 `navigator.languages` 与 `navigator.language`，并支持本地持久化状态记忆。
   - **LCD 风格 FPS 数字时钟**：右上角以 500ms 刷新率实时监测游戏运行帧率。
   - **“娱乐五分钟”极简主页**：“打开就玩，不用下载，找回小时候的快乐，不会上瘾的简单小游戏”；无冗余版权信息，支持键盘快捷键与一键重开。
