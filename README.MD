### 🎮 AI 辅助 HTML5 游戏开发实践：超级马里奥复刻

本项目旨在探索大语言模型在网页游戏开发中的实际应用能力与边界。通过对比不同模型的生成质量，记录了从提示词到可玩原型的完整迭代过程。

#### ✨ 项目特色

-   **零依赖纯原生实现**：游戏完全基于原生 HTML5 Canvas + Vanilla JS 构建，无任何第三方引擎或框架依赖。单文件即可运行，极致轻量，便于源码阅读与二次修改。
-   **AI 生成代码对照实验**：两个版本使用完全相同的初始 Prompt，直观呈现 Grok Fast 与 Hy4 Preview 在逻辑完整性、Bug 密度及修复成本上的差异，为 AI 编程选型提供真实参考。
-   **国际化多语言支持**：支持 7 种主流语言（简体中文、繁體中文、English、日本語、Português、Español、Français），具备浏览器语言自动识别与 localStorage 状态记忆。
-   **渐进式人机协作范式**：并非一次性生成成品，而是记录了“AI 生成 → 人工测试 → 精准反馈 → AI 修复”的完整闭环，展示了当前阶段人类开发者作为“AI 代码审查员”的最佳实践路径。

#### 🕹️ 核心游戏机制与功能

1. **六大主题关卡系统**
   - **关卡进阶**：草原 → 沙漠/黄昏 → 星夜 → 熔岩 → 冰雪 → 鬼域，难度逐关递增。
   - **主题专属配色与特效**：每关天空渐变、远山草丛、地面地砖、石块与砖块配色完全独立；暗色关卡（星夜/熔岩/鬼域）配有繁星闪烁，冰雪关卡具备全局实时飘雪粒子。
2. **手感调校与平台动作引擎**
   - **跳坑手感宽容度**：内置土狼时间（Coyote Time，离地短时间内仍可起跳）、跳跃预输入（Jump Buffer，落地前提前按键落地瞬间起跳）、坑沿吸附（Ledge Snap）。
   - **动态移动平台**：程序化正弦平滑移动平台，支持单向碰撞与角色站立随动。
3. **敌人 AI 行为系统**
   - **悬崖守卫机制**：每个跳坑落点均有板栗仔严密把守（敌人数 ≥ 坑数）。
   - **智能巡逻掉头**：敌人在悬崖边与坑沿会自动感知并掉头巡逻，不再无脑坠坑。
4. **道具收集与奖励结算**
   - **散落金币与金币弧线**：悬崖坑上方金币弧线与地面金币阵列，收集 +50 积分并伴随旋转动画与音效。
   - **双层可触达问号块**：合理隔行排布，支持站上下层连续顶击；15% 概率触发高爆幸运方块（+500 积分与专属粒子）。
   - **通关庆祝盛典**：终点夺旗触发烟花动画，过关结算界面触发全屏彩色纸屑彩带与 100~600 惊喜幸运随机奖励。
5. **UI 与交互系统**
   - **LCD 风格 FPS 数字时钟**：右上角以 500ms 刷新率实时监测游戏运行帧率。
   - **便捷控制栏**：顶部集成暂停/继续、重新开始与语言切换下拉框。
   - **响应式版本选择主页**：提供版本选择卡片、操作说明与底部 GitHub 仓库直达链接。
