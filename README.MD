# 🎮 玩五分钟 (Play 5 Mins)

HTML 网页游戏展示平台，探索大语言模型（Claude、Grok 等）纯 AI 生成游戏的极限实践。全单文件纯前端架构，无需下载安装，支持离线畅玩，集成 Cloudflare Web Analytics 流量统计。

---

## 📂 项目文件清单

### 1. `index.html`（游戏聚合主页）
平台导航主页，采用现代深色磨砂风格与居中自适应布局。集中展示平台收录的全部 HTML 游戏，支持单页直达与新标签页开启，适配电脑与移动端，集成本站流量统计。

### 2. `saltline.html`（3A 级 WebGL FPS 英文原版）
Anthropic 工程师 Felix Rieseberg 使用 Claude Fable 5.2 单提示词、8 小时无人工干预生成的 3D FPS 大作。建模、音效、雨水着色器全由 AI 实时算力生成，画质媲美 3A。

### 3. `saltline-cn.html`（SALTLINE 中文汉化版）
Saltline 的完整中文本地化版本。保持原版端游级 WebGL 第一人称射击手感与次世代视觉，全面汉化任务目标、无线电语音提示、画质设置及操作面板。

### 4. `mario-grok.html`（超级玛丽 · Grok Fast 版）
Grok Fast 生成的六关横版马里奥。包含草原、沙漠、星夜、熔岩等六大独立地貌关卡，集成 7 国语言切换、一键全景图文合成截图，并支持手机触屏虚拟摇杆操作。

### 5. `mario-hy4.html`（超级马里奥 · Hy4 Preview 版）
Hy4 Preview 生成的硬核马里奥。特色为悬崖自动掉头的智能板栗仔 AI、空中金币长廊与错层问号砖阵，支持 7 国语言、全景截图导出与手机触屏虚拟控制器。

## 🚀 运行与访问

- **在线访问**：直接部署到任意静态 Web 托管（如 Cloudflare Pages、GitHub Pages、Nginx）。
- **本地/离线游玩**：项目所有资源均已内联或本地化，断网环境下直接双击任意 `.html` 文件即可畅玩；也可通过本地命令启动服务：
  ```bash
  python3 -m http.server 8080
  ```
